# Molarity Calculator

Brand site for **[molaritycalculator.app](https://molaritycalculator.app)** — a free web tool to calculate mass, volume, or molar concentration for lab solutions, plus dilution and molar-mass helpers.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Main routes

- `/` — Molarity calculator (mass / molarity / volume)
- `/dilution-calculator` — C₁V₁ = C₂V₂
- `/molar-mass-calculator` — common compound MW lookup
- `/blog/*` — SERP-backed guides only
